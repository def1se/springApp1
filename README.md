# Библиотечная система учета книг

Веб-приложение для учета книг в библиотеке с возможностью регистрации читателей, выдачи и возврата книг.

## Описание проекта

Проект реализует цифровую систему учета книг для библиотеки, включая:

- Управление читателями (добавление, редактирование, удаление)
- Управление книгами (добавление, редактирование, удаление)
- Возможность выдачи книг читателям
- Возможность возврата книг в библиотеку
- Просмотр списков книг и читателей
